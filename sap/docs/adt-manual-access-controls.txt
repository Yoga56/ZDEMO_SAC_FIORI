MANUAL ROUTE: access control of the projection views (ADT, no abapGit)
======================================================================

Why: the OData service reads the ZC_SAC_* projection views. They were marked #NOT_REQUIRED, so they returned every owner's rows.
Each projection must be #CHECK and have an access control role that takes the conditions of the ZR_SAC_* view it projects on.

Do it in this order, and activate ONCE at the end, all together:

STEP 1  Edit the 15 projection views (data definitions). In each, change the line
            @AccessControl.authorizationCheck: #NOT_REQUIRED
        to
            @AccessControl.authorizationCheck: #CHECK
        Save (Ctrl+S) but do not activate yet. The 15 views:

          - zc_sac_caltask
          - zc_sac_comment
          - zc_sac_dastep
          - zc_sac_dataact
          - zc_sac_dim
          - zc_sac_fact
          - zc_sac_file
          - zc_sac_mastep
          - zc_sac_measure
          - zc_sac_model
          - zc_sac_multiact
          - zc_sac_share
          - zc_sac_story
          - zc_sac_version
          - zc_sac_widget

STEP 2  Create the 15 access controls. In Project Explorer: right-click the package ZDEMO_SAC_FIORI > New > Other ABAP Repository Object >
        Core Data Services > Access Control. Name = the name below, description = anything, template = Define Role (or empty),
        then replace the whole content of the editor with the block below. Save, do not activate yet.

STEP 3  Activate everything at once: Window > Show View > Inactive Objects, select all the ZC_SAC_* entries, Activate (Ctrl+F3).

STEP 4  Check: F8 on ZC_SAC_MODEL must show only SALES_PLAN and OPEX_PLAN for you (and your own models if you create any).

----------------------------------------------------------------------

### zc_sac_caltask
@EndUserText.label: 'Access control for calendar event (projection)'
@MappingRole: true
define role ZC_SAC_CALTASK
{
  grant select on ZC_SAC_CALTASK
    where inheriting conditions from entity ZR_SAC_CALTASK;
}
