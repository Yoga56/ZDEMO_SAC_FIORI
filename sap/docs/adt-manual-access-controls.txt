MANUAL ROUTE: access control of the projection views (ADT, no abapGit)
======================================================================

Why: the OData service reads the ZC_SAC_* projection views. They were marked #NOT_REQUIRED, so they returned every owner's rows.
Each projection must be #CHECK and have an access control role that takes the conditions of the ZR_SAC_* view it projects on.
Those conditions read the associations _ShareMe, _ShareAll (stories, models, files, actions, events) and _Model (versions, facts, comments),
so the projections of those objects must also list these associations (that is what the error "Element _SHAREME does not exist in entity" says).

Do it in this order and activate ONCE at the end, all together (Window > Show View > Inactive Objects > select all > Activate):

STEP 1A  Six projection views only need one line changed. In each, change
             @AccessControl.authorizationCheck: #NOT_REQUIRED     to     #CHECK
         ZC_SAC_DASTEP, ZC_SAC_DIM, ZC_SAC_MASTEP, ZC_SAC_MEASURE, ZC_SAC_SHARE, ZC_SAC_WIDGET
         (ZC_SAC_RUN is not touched.)

STEP 1B  Nine projection views get new full source: open the view, select all (Cmd+A), paste the block below, save (Cmd+S).
         ZC_SAC_CALTASK, ZC_SAC_COMMENT, ZC_SAC_DATAACT, ZC_SAC_FACT, ZC_SAC_FILE, ZC_SAC_MODEL, ZC_SAC_MULTIACT, ZC_SAC_STORY, ZC_SAC_VERSION

STEP 2   Create the 15 access controls (blocks at the end): right-click the package ZDEMO_SAC_FIORI > New > Other ABAP Repository Object >
         Core Data Services > Access Control. Name = ZC_SAC_MODEL and so on, paste the block, save. ZC_SAC_CALTASK exists already: replace its content.

STEP 3   Activate everything at once (all ZC_SAC_* views and access controls), then F8 on ZC_SAC_MODEL: only SALES_PLAN and OPEX_PLAN.
